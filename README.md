# Data Professional Survey Breakdown (Power BI Portfolio Project)

An interactive data visualization project designed to analyze the global landscape of the data profession. This dashboard breaks down demographics, compensation, job satisfaction, and industry trends based on survey data from hundreds of active data professionals across the world. 

*This project serves as the final project of a Power BI course. Data used might be real but is not researched enough to be able to draw real world insights*

## Project Overview & Business Value

As the data industry continues to grow rapidly, it can be difficult for aspiring professionals to navigate career paths, salary expectations, and skill requirements. The goal of this dashboard is to demystify the industry by providing actionable, data-driven insights into the real-world experiences of data professionals globally.

### Key Questions Answered:
* **Compensation:** How does average salary vary across distinct job titles (Data Analyst, Data Scientist, Data Engineer)?
* **Satisfaction:** Are data professionals generally happy with their current salary and work-life balance?
* **Skill Trends:** What are the most popular programming languages chosen by industry insiders?
* **Entry Barriers:** How difficult is it truly to break into the data field for beginners?

---

## Tech Stack & Skills Demonstrated

* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Data Transformation:** Power Query (ETL process, data cleansing, handling missing values, text parsing)
* **Data Modeling:** Star schema architecture featuring optimized relationships
* **Data Visualization:** Custom KPIs, custom color palettes, and advanced formatting for high visual impact
